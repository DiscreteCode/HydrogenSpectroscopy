# Sample spectra

All four files here are generated by `scripts/generate_sample_spectra.py`,
which calls the exact same backend pipeline (`spectroscopy.spectrum`,
`spectroscopy.analyzer`) the application uses at runtime -- nothing in
this directory is hand-drawn. Re-run that script whenever the physics
engine changes to keep these in sync.

Each file is a two-column CSV: `wavelength_nm,intensity`.

| File | What it is | Expected analyzer result |
|---|---|---|
| `hydrogen_balmer_emission.csv` | Pure laboratory hydrogen emission spectrum, Balmer series (n=3..6 -> n=2), no continuum, no noise. | N/A (reference spectrum, not run through the stellar analyzer) |
| `stellar_noisy_at_rest.csv` | Synthetic star, T=9000 K, no radial velocity, realistic photon noise (1.5%), moderate hydrogen line strength. | `HYDROGEN DETECTED`, 4/4 Balmer lines matched, ~0 km/s implied velocity |
| `stellar_doppler_shifted_180kms.csv` | Synthetic star, T=8500 K, receding at 180 km/s, 1% noise. | `HYDROGEN DETECTED`, redshifted lines, implied velocity within ~25 km/s of 180 |
| `stellar_no_hydrogen_control.csv` | Negative control: blackbody continuum plus noise only, **no** hydrogen lines injected. | `HYDROGEN NOT DETECTED` -- confirms the analyzer doesn't just say yes unconditionally |
